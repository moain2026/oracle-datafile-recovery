# وضع القاموس: استخراج الجداول بأسمائها
## القصة
بصفتي DBA وملف SYSTEM سليم أو شبه سليم، أريد استخراج جداول المستخدمين بأسمائها وأعمدتها وأنواعها حتى أعيد تحميلها في قاعدة جديدة.
## المتطلبات (صيغة EARS)
- REQ-002.1 — The resolver shall locate bootstrap$ and load obj$, tab$, col$, user$, seg$, ts$ from SYSTEM.
- REQ-002.2 — When a dictionary row is in a corrupt block, the resolver shall report the affected objects and fall back to inference (M4) for them.
- REQ-002.3 — The extractor shall export each table to CSV and SQL*Loader (control + data) preserving column order and types.
- REQ-002.4 — Where a database character set is known, the extractor shall convert text to UTF-8 and keep raw bytes for any undecodable value.
- REQ-002.5 — While running in a CDB, the resolver shall resolve objects per PDB (12c+).
## معايير القبول
- [ ] recall ≥ 99.9% و precision = 100% للصفوف في الكتل السليمة مقابل ground truth
- [ ] نص عربي AR8MSWIN1256 وAL32UTF8 يخرج مطابقاً bit-exact بعد التحويل
## خارج النطاق
- LOB خارج السطر والضغط (M5).
