# REQ-004 — الاستخراج تحت التلف والمخرجات الموسومة

| # | المتطلب | معيار القبول (قابل للقياس) |
|---|---|---|
| 004.1 | استخراج الصفوف السليمة من كتلة تالفة **جزئياً** بدل رفضها كلها | على مجموعة المختبر مع نمط `bitrot`/`torn`: كل صف يقع خارج المنطقة المُتلفة (حسب manifest) يُستخرج مطابقاً للحقيقة؛ **صفر** صفوف خاطئة في `verified/` |
| 004.2 | عند فقد القاموس: أسماء وهمية حتمية `OBJ_<objd>` و`COL_<n>` + مخطط مستنتج | تشغيلان على نفس الدليل = نفس الأسماء والمخطط بايتاً بايتاً |
| 004.3 | ثلاث طبقات مخرجات لا تختلط: `verified/` ، `inferred/` (مع ثقة ومصدر)، `rejected/` (مع السبب والبايتات الخام) | لا قيمة مستنتجة تظهر في `verified/` (اختبار آلي على كل الأنماط والبذور) |
| 004.4 | تقرير شرعي لكل ملف: حالة كل كتلة، Provenance لكل صف، SHA-256 قبل/بعد | SHA-256 قبل = بعد في كل تشغيل؛ كل صف في المخرجات له (file, rdba, slot, scn) |
| 004.5 | لا تعديل للدليل الأصلي أبداً؛ أي "إصلاح" في الذاكرة فقط | اختبار: الملف مفتوح read-only + verify_unchanged |

غير مشمول: كسر TDE؛ إعادة قاعدة متسقة معاملاتياً جاهزة للتشغيل.
